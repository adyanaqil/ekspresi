Skala Depresi, Kecemasan, dan Stres

Silakan baca setiap pernyataan di bawah ini dengan saksama. Berikan tanda pada angka 0, 1, 2, atau 3 yang paling menggambarkan seberapa sering pernyataan tersebut sesuai dengan keadaan Anda selama satu minggu terakhir.

Petunjuk Pengerjaan: Tidak ada jawaban benar atau salah. Jawablah sesuai dengan kondisi yang benar-benar Anda alami dan jangan menghabiskan terlalu banyak waktu untuk memikirkan setiap pernyataan.
0 Sama sekali tidak sesuai dengan saya
1 Sesuai dengan saya / pernah terjadi (sesekali)
2 Cukup sesuai dengan saya / cukup sering terjadi
3 Sangat sesuai dengan saya / sangat sering terjadi
1 Saya merasa sulit untuk menenangkan diri.
2 Saya menyadari mulut saya terasa kering.
3 Saya merasa tidak dapat merasakan perasaan positif sama sekali.
4 Saya mengalami kesulitan bernapas (misalnya napas menjadi sangat cepat atau sesak napas meskipun tidak melakukan aktivitas fisik).
5 Saya merasa sulit untuk memulai melakukan sesuatu.
6 Saya cenderung bereaksi secara berlebihan terhadap suatu keadaan.
7 Saya mengalami gemetar (misalnya pada tangan).
8 Saya merasa menghabiskan banyak energi karena rasa gugup.
9 Saya khawatir akan berada dalam situasi yang membuat saya panik dan mempermalukan diri sendiri.
10 Saya merasa tidak memiliki sesuatu yang dapat saya nantikan di masa depan.
11 Saya merasa mudah gelisah.
12 Saya merasa sulit untuk rileks.
13 Saya merasa sedih dan murung.
14 Saya merasa tidak sabar dengan apapun yang menghambat saya dalam menyelesaikan pekerjaan atau aktivitas yang sedang saya lakukan.
15 Saya merasa mudah panik.
16 Saya merasa kurang bersemangat terhadap apa pun.
17 Saya merasa diri saya tidak berharga sebagai seorang pribadi.
18 Saya merasa mudah tersinggung.
19 Saya menyadari detak jantung saya meskipun sedang tidak melakukan aktivitas fisik (misalnya jantung berdebar lebih cepat atau terasa berdetak tidak teratur).
20 Saya merasa takut tanpa alasan yang jelas.
21 Saya merasa hidup ini tidak bermakna.
